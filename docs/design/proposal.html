Proposal · October 2026 · for the Episodic server on CasaOS

EPISODIC PLAY

Your Steam library, wishlist and every achievement in one place, on your own server, reachable over Tailscale. Bundles like Kingdom Hearts 1.5+2.5 are split into the games they contain, with a progress bar for each.

Is it possible?

Yes. Steam's official Web API gives owned games, playtime, every achievement with its unlock time, icons, hidden flags and global rarity.

Bundles split per game?

Yes, but Steam doesn't do it for us. KH 1.5+2.5 is one Steam app with one combined list. The app splits it with a saved mapping, prefilled automatically and fixable by hand.

Where it should live

As a third Play side of Episodic, next to Watch and Read. Accounts, offline mode, backups, notifications, CasaOS and Tailscale already work there.

I · The shape of it

A Play side, not a new app

Episodic already switches between Watch and Read, and each side has its own home, search, library, stats and look. Read gets amber and serif headings, and Play would get its own look the same way. Episodic was built to take new media types: a registry, provider interfaces and generic statuses. Games fit that model well, the way books and manga did.

Play side inside Episodic RECOMMENDED

  • One container and one login. One install of the phone app with a Watch | Read | Play switch.
  • Comes with what's already built: household accounts, PWA, offline tracking, nightly backups, JSON export, Web Push/ntfy/Discord, calendar and iCal feed, background jobs.
  • Links across sides: the Arcane show next to League of Legends, the Witcher books next to the games.
  • New: the game media type, Steam/IGDB providers, achievement tables, bundle groups.

Separate app

  • A clean start, with a fully themed shell everywhere, including login and settings.
  • Rebuilds auth, PWA, offline, backups and notifications that Episodic already has (weeks of work).
  • A second app to install in CasaOS, a second Tailscale address and a second icon on the phone.
  • Same stack either way: SvelteKit + SQLite in one Docker image, so splitting it out later stays possible.
II · The hard question

Splitting a bundle into its games

On Steam, KINGDOM HEARTS -HD 1.5+2.5 ReMIX- is one app (2552430) with one achievement list covering Kingdom Hearts Final Mix, Re:Chain of Memories, Kingdom Hearts II Final Mix and Birth by Sleep Final Mix. Players on its forum confirm the list isn't divided per title. Some worlds repeat across the games, so names alone are ambiguous. Steamhunters shows the same achievements in per-game lists, which proves the split can be done, but someone curated it by hand.

Steam's API has no "sub-game" or "DLC" field on an achievement. What it does give, for each achievement: an internal name (API name), a display name, a description, an icon, a hidden flag, and the order Steam lists them in. The app builds the split from those in four layers. The first layer that applies wins, and the result is saved per bundle and shared by everyone on the server.

Layer How it works Effort for you
1. Shipped splits The repo includes a small JSON file per known bundle (KH 1.5+2.5, KH 2.8, Mass Effect Legendary, Master Chief Collection, Metal Gear Master Collection, Crash and Spyro trilogies…), mapping each API name to a game. Contributions are a pull request. none
2. Pattern rules Many publishers prefix API names per game (for example KH1_… or BBS_…, which needs checking for each game). Rules such as "name starts with", "position 1–56 in Steam's order" or "description mentions Birth by Sleep" assign whole blocks at once. a minute
3. Suggested groups IGDB marks a bundle as a parent game with child games, so the groups (names, covers, release years) are created for you, and the rules editor only has to fill them. none
4. By hand Anything left over appears under Unassigned and is dragged into a group. A few edge cases stay: an achievement that spans the whole collection gets its own "Collection" group. a few taps

The same groups handle DLC (Ashes of Ariandel and The Ringed City inside Dark Souls III, for example). They also handle the reverse case of one game owned twice, like Elden Ring on Steam and PS5: link the two and see a single progress bar. On PlayStation, trophy lists already come split into base game and DLC groups, so nothing needs mapping there.

Steam allows 100,000 API calls a day per key, far more than one household needs. A background job checks recently played games every 15 minutes (an unlock appears within minutes) and does a full pass at night. The first import of a large library takes a few minutes and runs in the background.

IV · What it does

Features

The first group is what you asked for. The others are proposals, roughly in order of value.

Core: library and achievements
◈
One-click Steam import

Every owned game with playtime and achievements, refreshed on its own. Wishlist imported too.

⚑
Statuses that fit games

Backlog, Playing, Beaten (credits rolled), Perfected (100%), On hold, Abandoned, Wishlist. "Beaten" and "100%" are kept apart on purpose.

✦
Full achievement list

Icon, description, unlock date and time, global rarity, sorted or filtered by locked, rarest, recent.

⧉
Bundles and DLC split

Per-game progress inside a collection, plus a separate bar for each DLC. Owning a game on two platforms counts as one.

◐
Spoiler-safe hidden achievements

Blurred until you tap. Optionally hide the names of story achievements for games you haven't finished.

✚
Any game, any platform

Add Switch or PS games from IGDB search. Tick achievements by hand, or connect PSN, Xbox or RetroAchievements later.

For 100% runs
⚠
Missable flags

Mark an achievement missable (an NPC questline in Dark Souls III, an ending), with a note on when. Missables are shown first on the game page while you play.

✎
Notes and guide links

A personal note on each achievement, and one-tap search on your favourite guide site (Fextralife, PowerPyx, Steam guides).

☰
Custom checklists

Your own 100% beyond achievements: every boss in Elden Ring, every Sekiro prosthetic, all Hollow Knight charms. Track them like achievements.

⌖
Pinned targets

Pin the 3–5 achievements you're working on. They show on Home and the phone's lock-screen notification.

⌛
Time to 100%

HowLongToBeat completionist hours minus your playtime: "about 18 h left". Sort the backlog by quickest perfect.

⇣
Almost there

Games closest to 100%, and ones you left at 90%+ two years ago. The best place to start an evening.

Library and wishlist
€
Price alerts

A notification when a wishlist game hits your target price or its historical low (IsThereAnyDeal).

▦
Release calendar

Wishlisted games in the existing Calendar and iCal feed, next to episodes and books.

⚜
Franchises and series

All FromSoftware games, in release order, with your progress on each. The Souls series as one shelf, like book series on the Read side.

✧
Ratings, reviews, journal

A rating and a few lines when you finish, plus an optional play journal ("Beat Malenia after 61 tries").

Stats and delight
♛
Hall of Fame

A gold shelf of every perfected game, with the date and the rarest achievement of each.

▤
Stats

Perfect games, average completion rate, unlocks per month (heatmap), rarest unlocks, hours per genre, longest hunts.

🔔
Unlock notifications

Phone push, ntfy or Discord when an achievement unlocks, and a big message for a 100%. Reuses Episodic's notifications.

♫
Themes and sounds

Ember (FromSoftware), Pixel (16-bit), or Episodic's default. Optional unlock sounds. Each theme renames a few things (the home screen is the Bonfire in Ember).

⚔
Household rivalry

Everyone on the server tracks separately; compare progress on a shared game.

VII · Getting there

Build order

Each step is a release you can use on your server, like the phases Episodic shipped in.

2.4Play side and Steam library

The game media type, Watch | Read | Play switch, Steam key and SteamID in Settings, import of owned games and playtime, IGDB search for other platforms, statuses.

2.5Achievements

Schema, unlocks and rarity; the game page; the sync job every 15 minutes plus nightly; Home, Almost there, Recent unlocks; unlock notifications.

2.6Bundles and DLC

Groups, rules, split editor, shipped split files for the first bundles (KH 1.5+2.5 first), linking the same game across platforms.

2.7Ember theme

The FromSoftware look across the Play side, SteamGridDB artwork, the 100% moment, Hall of Fame.

2.8Hunting tools

Missables, notes, pinned targets, custom checklists, HowLongToBeat times.

2.9Wishlist and prices

Steam wishlist import, IsThereAnyDeal alerts, releases in the Calendar and iCal feed.

3.0More platforms and Pixel

RetroAchievements, PlayStation, Xbox; the Pixel theme; stats heatmap.

What you'd set up on the server

Nothing new to install: update the Episodic image in CasaOS as usual. Then add three keys to the app's settings in CasaOS: STEAM_API_KEY, IGDB_CLIENT_ID and IGDB_CLIENT_SECRET (optionally STEAMGRIDDB_API_KEY). Each person enters their own SteamID under Settings. Your Steam profile's Game details must be public, or Steam returns no achievements.

VIII · Your call

Before building

  1. Play side or separate app? I recommend the Play side of Episodic.
  2. Which look? Ember, Pixel, or both as switchable themes. Ember everywhere on the Play side is my pick.
  3. Which platforms besides Steam? PlayStation for Bloodborne, Switch as manual checklists, RetroAchievements?
  4. Start with 2.4 and 2.5? That's a working library and achievement tracker, and the bundle split follows right after.
